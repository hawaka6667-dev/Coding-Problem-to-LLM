# Coding-Problem-to-LLM

A Chrome extension that sends coding problems from Exercism, LeetCode, etc. directly to your LLM (DeepSeek, ChatGPT, etc.) with one click.

## Features

- 🎯 One-click send: `Ctrl+Shift+E` or click the extension button
- 🌐 Support for Exercism, LeetCode (more coming)
- 🤖 Works with DeepSeek, ChatGPT, Claude (extensible)
- ⚡ Automatic code extraction and insertion

## Quick Start

1. **Install**
   - Open `chrome://extensions/`
   - Enable **Developer mode**
   - Click **Load unpacked** and select this folder

2. **Use**
   - Open a coding problem (Exercism/LeetCode)
   - Open your LLM chat in another tab
   - Press `Ctrl+Shift+E` or click the extension button
   - Your code is sent!

## Requirements

- Chrome browser
- Active session on both the coding platform and LLM service
- LLM tab must be open
